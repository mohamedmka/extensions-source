# Prochan Extension

**Prochan** هو موقع تقرأ فيه المانهوات والمانجا بجودة عالية باللغة العربية.

## الميزات

- 📚 قراءة المانهوات المترجمة للعربية
- 🔄 تحديثات مستمرة للفصول الجديدة
- 🏷️ تصنيفات متنوعة (Shounen, Shoujo, Seinen, إلخ)
- 📖 واجهة سهلة الاستخدام

## الرابط

- الموقع الرئيسي: https://procomic.pro/ar
- أحدث الفصول: https://procomic.pro/ar/updates
- المانهوات الشهيرة: https://procomic.pro/ar/series

## المتطلبات

- Tachiyomi أو تطبيق manga reader متوافق
- اتصال إنترنت مستقر

## الملاحظات

- بعض المانهوات قد تتطلب تسجيل دخول
- يحتفظ الموقع بحقوق النشر الخاصة به
